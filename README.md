# AutoHook

全自動釣魚插件：自動拋竿、判斷魚訊自動收竿、自動撈魚，並支援刺魚。

## 功能

- 自動拋竿、依魚訊型態（！／！！／⁉ 等）自動收竿，可依魚種／魚餌個別設定判斷條件
- 自動撈魚（Mooch）、雙撈魚，自動使用魚餌與活餌轉換
- 自動使用釣魚技能：identical cast、collect、intuition、chum、cordial、patience、
  prize catch、release fish 等
- 刺魚（Spearfishing）自動判斷時機與力道出手，可自訂各魚種擊中策略
- 依條件切換的自訂預設集（preset），可依天氣、時間、地點等條件自動切換釣組
- 天氣預報與時間軸顯示，方便規劃限定魚種的出竿時機
- 社群預設集：可下載、分享他人建立好的釣魚／刺魚預設集
- 選配整合**塔塔露誇獎**（TataruPraise）：釣到稀有魚時可請它念一句提醒你回來
- 提供 IPC 供其他插件（如 Questionable）呼叫自動釣魚

## 指令

`/autohook`、`/ahcfg`、`/ahon`、`/ahoff`、`/ahtg`、`/ahpreset`、`/ahstart`、`/ahbait`、`/bait`、`/agpreset`

## 安裝

在 Dalamud 設定的「自訂插件庫」加入
`https://raw.githubusercontent.com/ffxiv-tc-port/DalamudPluginsTC/main/repo.json` 並啟用，
再從插件列表安裝。
